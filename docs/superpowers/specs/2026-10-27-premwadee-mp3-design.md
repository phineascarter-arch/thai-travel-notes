# 固定 Premwadee Neural 音源

使用者已同意將全站例句、標題詞句與逐詞拆解切換至與 thai-song-vocab 相同的 `th-TH-PremwadeeNeural` MP3，完成後提交 GitHub main 並部署既有 Vercel 網站。

- 從最新版 notes 資料收集所有 thai 欄位，完全相同文字只生成一次，以 SHA-256 檔名儲存在 public/audio/premwadee/，manifest 對應原文與檔名。
- edge-tts 以 +0% 速度、+0Hz 音高、+0% 音量產生標準口語 MP3；最多重試三次，不改用其他聲音。
- 播放使用單一 HTML audio，按下立即呼叫 play，不等待線上合成；切換詞句先停止前一段。預設慢速 0.71，保留短詞既有 0.82 速度，提供正常／慢速與原生播放控制，保留音高。
- 例句、單字、複習題、唱片與運河互動共用同一播放器。無語音包需求，不回退到裝置語音。音檔缺漏、解碼與播放遭拒時顯示可理解錯誤並允許手動重播。
- 全量核對 MP3 覆蓋、非空與解碼，測試中斷、錯誤與速度，建置與瀏覽器驗證後僅提交本次檔案，確認 Vercel 成功。沒有 iPhone 實機，不宣稱實機測試通過。
